# Dual Sports

A 1v1 mobile game: a basketballer against a footballer, with one ball that turns into a basketball in the basketballer's hands and a football at the footballer's feet. First to 5 wins.

Play it by opening `index.html` in a browser. Hold the phone sideways. Everything is in that one file.

## Controls

Touch: joystick to move, Shoot, Steal / Tackle, Run (hold, only while defending). Move or resize any button in Settings.
Keyboard: WASD or arrows to move, Space to shoot, Shift to steal or tackle, R to run, Esc to pause.

## Online

Menu, then ONLINE. One player taps HOST and reads out the 5-digit code; the other taps JOIN and types it. Both need internet and the page must be served over https (GitHub Pages is). Uses PeerJS, loaded from a CDN.
